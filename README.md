# Command Center — public builds

This repository holds **public Windows builds only**. There is no source code here.

- Open the newest release and download `CommandCenter-<version>-setup.exe`, then run it. Windows SmartScreen may warn the first time, because the installer is not signed yet: click **More info**, then **Run anyway**.
- No login and no GitHub token are needed, to download or to update. Command Center checks this repository's releases and updates itself (Settings → Updates).
- Your accounts (Notion, Todoist, Google, Plaid and the rest) are connected by you in Setup and stay on your PC, encrypted. Nothing about them is in this build.
- Full public releases are normal releases. Test builds for friends are marked **Pre-release**.
